# عملاء آلي — One Brain, Five Faces

كل الواجهات تتكلم مع نفس العقل (API واحد على حاسوبك):

```
POST /api/ask        {"message": "نصك", "sid": "اختياري"}   →  {"ok": true, "reply": "...", "sid": "..."}
GET  /api/health                                            →  {"ok": true, "service": "aali", ...}
```

شغّل كل شيء بنقرة واحدة:  `scripts\start_all.bat`
(يفتح خادم العقل على 5055 + n8n على 5678 + واجهة الويب).

---

## 1) Web — محلياً أو من GitHub Pages

- **محلياً:** `scripts\start_all.bat` ثم افتح `http://127.0.0.1:5055` (النسخة القديمة)
  أو افتح `web\index.html` مباشرة واضبط العنوان من ⚙︎ إلى `http://127.0.0.1:5055`.
- **من GitHub Pages (للتجربة والمعاينة):**
  1. ارفع محتويات مجلد `web\` إلى مستودع (أو مجلد `docs/` في مستودعك).
  2. Settings → Pages → Source: `main` branch → Save.
  3. افتح `https://<user>.github.io/<repo>/` — ثم من ⚙︎ الإعدادات داخل التطبيق
     ضع عنوان حاسوبك: `http://<IP-الحاسوب>:5055`.
  4. لاحقاً عند شراء النطاق: أضف ملف `CNAME` في نفس المجلد واضبط Custom domain.
- ملاحظة أمان صادقة: الخادم الحالي بلا كلمة مرور وهو مصمم للشبكة المنزلية.
  لا توجّه له منفذاً من الإنترنت مباشرة؛ ضعه خلف VPN/Tailscale أو أضف توكن
  (أستطيع إضافة Bearer-token بسيط لاحقاً).

## 2) iPhone — طريقتان

**أ) فوراً — PWA (بدون ماك):**
1. افتح صفحة الويب (محلية أو من GitHub Pages) في Safari على الآيفون.
2. زر المشاركة → **Add to Home Screen** → يصبح تطبيقاً بأيقونة النجمة الذهبية،
   شاشة كاملة، ويعمل كتطبيق مستقل.

**ب) التطبيق الأصلي — Xcode (على الماكبوك):**
1. انسخ مجلد `ios\` إلى الماكبوك (AirDrop/USB/Git).
2. افتح `ios\Aali.xcodeproj` في Xcode.
3. اختر فريق التوقيع الخاص بك (Signing & Capabilities → Team) — حسابك المدفوع.
4. شغّل على جهازك: افتح التطبيق → ⚙︎ → أدخل `http://<IP-الحاسوب>:5055` → اختبار الاتصال.
5. للنشر على App Store لاحقاً: Product → Archive من نفس المشروع.

ملفات المشروع: `AaliApp.swift` (نقطة البداية)، `Theme.swift` (الثيم + مؤشر
التفكير المداري)، `APIClient.swift` (اتصال API + جلسات)، `ChatView.swift`
(شاشة المحادثة)، `SettingsView.swift` (عنوان الخادم + اختبار الاتصال).
RTL كامل، لكل رسالة اتجاهها حسب اللغة (عربي RTL، كود/إنجليزي LTR)، اهتزاز
خفيف عند الإرسال.

## 3) CLI — الطرفية

```bash
.venv\Scripts\python aali_cli.py                      # محادثة تفاعلية
.venv\Scripts\python aali_cli.py "اشرح لي RoPE باختصار"
.venv\Scripts\python aali_cli.py --server http://192.168.1.10:5055
```
أوامر داخلية: `/new` محادثة جديدة، `/quit` خروج. يثبّت الجلسة في `.aali_cli_sid`
فتكمل نفس المحادثة بين التشغيلات. (ثبّت `rich` للوحة أجمل — يعمل بدونه أيضاً.)

## 3.5) منصات خارجية — اربط آلي كنموذج في أدواتك

آلي يكشف واجهة نموذجية قياسية على نفس المنفذ، فأي أداة تتكلم مع النماذج
تستطيع استخدام آلي كنموذج:

```
Base URL : http://<عنوان-الحاسوب>:5055/v1
API Key  : مفتاح آلي حقيقي (من /admin أو /signup)
Model    : aali   (أو aali-local)
```

- **n8n:** عقدة HTTP Request → POST `.../v1/chat/completions`،
  Header `Authorization: Bearer <مفتاح>`، جسم `{"model":"aali","messages":[{"role":"user","content":"..."}]}`.
  (استخدم أيضاً أداة آلي `make_n8n_workflow` لتوليد سير عمل جاهز للاستيراد.)
- **أدوات المحادثة المفتوحة (LibreChat، Cline، Open WebUI…):** اضبط
  Base URL على `http://<host>:5055/v1` والمفتاح على مفتاح آلي.
- **أي عميل نموذجي آخر:** نفس Base URL + المفتاح، النموذج `aali`.
- `GET /v1/models` يعرض النموذجين (`aali`, `aali-local`) للعملاء الذين يكتشفون النماذج.
- `stream: true` مدعوم (SSE) لنفس العميل، بدون تغيير.

من داخل تطبيق Desktop: اضغط أزرار الربط في الزاوية السفلية لنسخ الإعدادات
الجاهزة لكل منصة.

> الأمان: نفس قواعد آلي — لا مفتاح = جهازك فقط؛ وبعيداً عن 127.0.0.1 أي
> مفتاح غير مدير يُجبر على سياسة الضيف (بدون أوامر/حذف).

## 4) Desktop — نافذة أصلية

```bash
.venv\Scripts\python desktop_app.py
```
نافذة WebView2 بنفس تصميم الويب، تفتح على الشاشة مباشرة كتطبيق مكتبي.

## ملاحظات تشغيل

- كل العملاء يتشاركون نفس الجلسات عبر `sid` — ابدأ محادثة على الويب وأكملها من CLI.
- الخادم يستقبل من الشبكة المحلية (0.0.0.0). اعرف IP حاسوبك بأمر `ipconfig`.
- المكوّنات مستقلة: لو وقع الخادم، تعمل الواجهات وترفض بلطف (سهم حالة الاتصال في الأعلى).
